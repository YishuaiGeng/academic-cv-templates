# 学术申请简历填写指南

[返回模板首页](../README.md)

本指南面向本科高年级学生、硕士生、博士生及近期毕业生，帮助你把已有经历整理成用于申请的学术简历（Academic CV）。重点是让评审快速看清：**你学过什么、研究过什么、具体做了什么，以及这些经历与申请目标有什么关联。**

模板中的 `[...]` 和 `20XX` 均为填写提示，不代表任何人的真实经历；下文的写法骨架也需替换后使用。申请单位规定的格式、页数和内容要求始终优先。

## 明确申请目标

先阅读项目或岗位说明，确认材料要求、研究方向和评审关注点，再选择相关经历。建议先保存一份完整的经历记录，每次申请从中选取内容，并保留该次提交的版本。

| 申请场景 | 简历应重点回答的问题 | 优先展示的内容 |
| --- | --- | --- |
| 硕士、博士项目及联系潜在导师 | 是否具备相关基础和研究潜力？ | 教育背景、研究兴趣、科研或毕业课题、相关方法与成果 |
| 科研助理、科研实习 | 能否承担岗位的具体研究任务？ | 相关项目、本人完成的工作、方法与工具、可查看的成果 |
| 访学、交换、联合培养 | 当前研究与接收团队如何衔接？ | 在读阶段、研究主题、已有工作、学术交流经历 |
| 奖学金、研究资助 | 哪些经历能支持评选标准？ | 学业表现、研究成果、荣誉，以及要求关注的教学或服务经历 |

简历负责概括经历与成果。申请动机、详细研究设想和完整论证通常由个人陈述、研究计划等材料承担；成绩单和推荐信按要求另行提交。

## 选择栏目与顺序

**现有模板已覆盖多数学生学术申请需要的基础内容，无需为凑齐栏目增加经历。** LaTeX 版默认包含教育背景、科研成果、实习经历和专业能力；科研成果分为论文、专利、参与著作，荣誉与竞赛可归入对应教育经历。源码另外提供可选的科研与项目经历、自我评价骨架，默认注释，可按需启用。Word 版包含教育背景、论文发表、项目经历、荣誉奖项及研究兴趣与能力。栏目名称和数量都可以调整，两种格式不要求逐栏对应。

姓名、有效联系方式和教育背景是基础。研究型申请通常应重点展开科研或相关项目；研究兴趣可以独立列出，也可以融入教育背景。论文、工作经历、奖项等栏目有相应内容再保留。

一个适合多数研究型申请的起点是：

> 个人信息 → 教育背景 → 研究兴趣 → 科研经历 → 学术成果 → 专业能力 → 荣誉及其他相关经历

如果已有成果是主要优势，可以将成果提前；申请科研岗位时，可以将最相关的研究或项目经历提前。同一栏目内通常按时间倒序排列。优先选择与目标有关、能够说明本人贡献的经历，并给它们更多篇幅。

以下模块按实际经历和申请要求补充，均非学生简历的统一必备项：

| 可选模块 | 值得保留的信息 | 需要区分的情况 |
| --- | --- | --- |
| 学术报告与海报（Presentations and Posters） | 题目、活动名称、时间、展示形式及报告人 | 参会、论文被会议接收和本人作报告是不同经历 |
| 教学与助教（Teaching Experience） | 课程、单位、时间、承担任务与参与范围 | 写清辅导、批改、实验指导或独立授课等实际职责 |
| 其他研究成果（Research Outputs） | 软件、数据、专利、译作、作品等，本人贡献及可访问链接 | 软件使用者与开发者、专利申请与授权应分别表述 |
| 学术服务（Academic Service） | 审稿、学术活动组织等具体角色、时间及工作 | 不必将一般活动参与写成学术任职 |
| 研究资助（Research Funding） | 资助方、项目、时间及本人身份 | 参与导师项目不等于独立获得该项目资助 |
| 推荐人（References） | 经推荐人同意后列出其姓名、职务、单位及联系方式 | 申请系统另行收集时通常无需重复列出 |

教授或 PI 的职业履历可能包含长期经费、学生指导、课程建设及学术任职记录。普通学生没有这些内容很正常，不需要照搬资深学者的栏目设置。

## 逐项填写正文

### 姓名与联系方式

保留姓名和常用邮箱；电话、所在城市、个人学术主页、ORCID 或成果主页按需要添加。姓名拼写应与申请系统、证件及其他材料保持对应。跨国申请填写电话时可附国家或地区代码。

选择能直接查看相关内容的主页或作品链接，避免堆放空白账号。出生日期、婚姻状况、身份证号和详细住址通常无需主动填写，申请方另有要求时按要求处理。

LaTeX 模板为邮箱、电话、所在地提供统一图标；Scholar、GitHub 和个人主页可按相关性选择，不必全部放入顶部。图标旁保留可读文字。导师姓名前的网络图标可链接导师的院校介绍或个人页面。先替换示例网址，再导出 PDF 检查链接。导师职称、院士等称谓按实际情况填写，不照搬示例或他人的身份。

### 教育背景

按时间倒序列出学校、专业、学位和就读时间。在读经历应明确写出“在读”或预计毕业时间；预计获得的学位不能写成已经获得。联合培养、交换等经历注明性质及所在机构，避免让人误以为是另一项完整学位。

```text
[学校名称]｜[专业名称]｜[学位名称，在读时注明]｜[开始年月]—[结束年月或至今]
预计毕业：[年月，仅在读时填写]
可选补充：[学位论文题目]；[导师]；[与申请相关的课程]
```

GPA、排名、导师和课程均按要求与关联度选择。填写 GPA 时注明满分，填写排名时说明范围与人数，例如使用 `[名次]/[本专业同届人数]` 的格式；不要自行换算为未获认可的成绩体系。在读成绩可注明统计截至时间。相关课程只选能说明基础的几门，完整成绩由成绩单提供。

### 研究兴趣

用一两行概括 1–3 个相对具体的主题，可以结合研究对象、问题或方法。只写“人工智能”“社会科学”等大领域，通常难以说明方向；列出过多互不相关的主题也会分散重点。

```text
研究兴趣：[具体问题或研究对象]；[相关方法或主题]。
Research Interests: [specific problem or subject]; [related method or topic].
```

研究兴趣可以包含希望继续探索的方向，但要与已经掌握的能力区分。结合自己的基础说明匹配点，避免直接复制目标导师的研究关键词。

### 科研与项目经历

这是研究型申请最值得展开的部分。每项经历先列课题名称、时间、所属团队及本人角色，再用若干条简短描述说明研究问题、本人工作和实际进展。

写作时依次回答：

1. **问题是什么？** 研究对象、待解决的问题或项目目标是什么？
2. **你做了什么？** 本人负责哪个环节，采用什么方法，完成了哪些具体工作？
3. **得到什么证据？** 形成了什么发现、材料或交付物，如何评价，目前完成到哪一步？

可参考以下中英文骨架，选择适用的部分，不必机械保留每个标签：

```text
[研究或项目名称]｜[本人角色]｜[团队或单位]｜[起止年月]
• 围绕[具体问题]，研究[对象、资料或数据范围]。
• 本人负责[具体任务]，采用[方法或工具]完成[可说明的工作]。
• 形成[实际发现或产出]，通过[评价方式或证据]检验；目前处于[真实进展]。
```

```text
[Project title] | [Role] | [Group or institution] | [Dates]
• Investigated [specific question] using [data, sources, or materials].
• [Action verb in the appropriate tense] [personal task] using [method or tool].
• [Action verb in the appropriate tense] [actual finding or output], assessed through [evidence or evaluation].
```

“参与研究”“协助项目”“负责数据处理”还不够具体，可以继续追问：处理什么资料，采用什么步骤，产出什么，哪些部分由自己完成？例如将“负责实验”展开为 `针对[问题]设计并完成[具体实验]，用[评价方式]分析[对象]`，再填入真实信息。

团队成果和个人贡献应分别交代。只有在确实承担相应职责时，才使用“主导”“独立完成”“提出”等表述；合作完成同样可以清楚展示价值。

结果不必全部量化。实验研究可给出评价条件、指标或对照；访谈、文本、田野和档案研究可说明材料范围、分析方法及形成的发现。使用数量或提升比例时，应有记录支持，并交代比较对象或统计口径；不要为了显得有成果而编造数字。正在开展的研究只写已完成的工作与当前进展。

### 论文与其他学术成果

论文条目应包含作者、题目、期刊或会议、年份及实际状态；已有卷期页码、DOI 或稳定链接时可补充。统一引用格式，保留真实作者顺序，可加粗本人姓名；共同第一作者、通讯作者等标记须与实际记录一致。LaTeX 的 `\cvname{本人姓名}` 会同时加粗并加下划线；引用格式允许时可用 `et al.` 省略本人之后的作者，不能因此改变前序作者或本人顺位。期刊、会议及论文集名称以正式记录为准，不统一强加同一种会议前缀。

```text
[作者列表，标出本人]．[题目]．[期刊或会议]，[年份]．[必要的书目信息及实际状态]．[DOI 或链接]
[Authors, with your name highlighted]. [Title]. [Venue], [Year]. [Bibliographic details and actual status]. [DOI or URL]
```

不要把所有稿件都无区别地列为“已发表”。可按实际情况分组，或逐条标注：

| 状态 | 常用英文 | 填写边界 |
| --- | --- | --- |
| 已发表 | Published | 已正式出版或在线发表，使用已有书目信息 |
| 已录用、待发表 | Accepted / In press | 已获得正式录用；尚无卷期页码时不补造信息 |
| 预印本 | Preprint | 已公开的稿件版本，注明平台、编号或链接；不等同于同行评审录用 |
| 已投稿、审稿中 | Submitted / Under review | 按实际流程状态填写，与已录用成果区分；是否列出遵循学科与申请要求 |
| 准备中 | In preparation | 通常可放在科研经历中说明；确需列出时单独标注，避免把初步设想列为成果 |

一篇预印本可能同时在审，必要时同时说明两种状态，但不要重复计为两篇论文。毕业论文可写在教育或科研经历中，不应直接当作期刊发表记录。其他成果按本学科惯例列出类型、本人角色、完成或公开状态及链接；专利需区分申请与授权，写明发明人顺位。研发时间与申请日、授权日是不同信息；不能用研究起止时间代替专利的法律状态或申请日期。参与著作应补充书目信息、出版状态及本人负责的章节或工作。

同一项目可以出现在科研经历和成果栏目：前者解释研究工作与个人贡献，后者提供规范的成果信息。两处不必重复整段摘要。若论文下方已经充分说明工作，可以不再设重复的科研经历；实习期间完成的项目可直接按任务列在该段实习下。独立项目有额外信息时再单设章节，通常放在实习之前。

### 专业与语言能力

围绕申请需要组织研究方法、工具技术和语言能力，尽量说明能完成什么任务，并让前文经历提供支撑。

| 内容 | 建议写法 |
| --- | --- |
| 研究方法 | `[方法名称]：用于[具体研究任务或分析对象]` |
| 软件与技术 | `[工具或技术]：可完成[具体操作、分析或开发任务]` |
| 语言考试 | `[考试名称]，[成绩及量表]，[考试年月]；[要求提供的分项成绩]` |
| 专业资格 | `[资格名称]，[颁发机构]，[取得时间或当前有效状态]` |

避免只列“熟练”“精通”或用星级、进度条表示能力。未出分的考试不要填预计成绩；考试成绩是否仍被接受，以申请方规则为准。

### 荣誉、工作与实践经历

荣誉条目通常写名称、授予单位和时间，必要时补充等级、评选范围或依据。只有掌握准确依据时才填写获奖比例，不自行推断“前百分之几”。奖学金、竞赛奖项和研究资助应按实际性质命名。

奖项数量较少时，可放入对应学校的教育经历，校级荣誉和学科竞赛分别列点，每项竞赛单独换行。归属与获奖时间按实际记录填写，不把研究生阶段的奖项移入本科经历；数量较多时再单独设荣誉栏目。

工作、实习和实践经历优先保留与研究方向或岗位任务有关的部分，写清单位、角色、时间、具体任务及交付物。使用与科研经历相同的“任务—本人行动—实际结果”思路，避免只复制岗位职责。单位、部门或岗位与时间可放在同一标题行；不同项目分条展开，保留关键方法、数据规模、评价条件和本人职责，不必为追求条目短而删去能说明贡献的信息。

## 经历较少或研究未完成时怎么写

| 情况 | 建议处理 |
| --- | --- |
| 没有论文 | 删除论文栏目，重点写科研、毕业论文或相关项目；无需保留“暂无”或虚构稿件 |
| 没有正式科研经历 | 可选与申请相关的课程研究、毕业设计或独立项目，如实注明性质；说明问题、方法、本人工作和产出 |
| 研究仍在进行 | 标明起止时间与当前阶段，写已完成的文献梳理、方案、资料收集、实验或分析；将计划与已完成工作分开 |
| 只有少量经历 | 展开最相关的一两项，交代具体贡献；不靠增加无关活动或大段自我评价填满版面 |
| 跨专业申请 | 解释已有方法、课程或项目如何支持新方向，保留可迁移的能力；不把拟学习内容写成已掌握能力 |
| 没有奖项、助教或学术服务 | 删除相应栏目，对多数学生而言这些都不是必须补齐的内容 |

学生简历的说服力来自清晰、相关且有依据的经历。成果数量不多时，准确说明自己怎样提出问题、完成工作和理解结果，同样能展示研究潜力。

## 保持中英文版本一致

建议先整理一份事实清单，包括学校与学位名称、时间、项目角色、作者顺序、成果状态和成绩，再据此维护两个版本。中英文可以调整句式和栏目顺序，但相同经历的事实应一致。

| 中文栏目 | 常用英文名称 |
| --- | --- |
| 教育背景 | Education |
| 研究兴趣 | Research Interests |
| 科研经历 | Research Experience |
| 相关项目 | Selected Projects |
| 学术论文 | Publications（在投及预印本等需标明或另分组） |
| 其他研究成果 | Research Outputs |
| 荣誉与奖学金 | Honors and Scholarships |
| 教学与助教 | Teaching Experience |
| 专业与语言能力 | Research Skills and Languages |

学校、院系、专业和学位名称优先采用官方英文名称。不要仅凭中文学位名称推断英文授予类型；学位名称、培养阶段和预计毕业状态均应与实际记录一致。

每个版本统一日期格式，例如中文用 `2024.09—至今`，英文用 `Sep 2024–Present`；这些仅示范格式，需换成本人日期。预计毕业可分别写 `预计毕业：[年月]` 和 `Expected graduation: [Month Year]`。已完成的英文工作通常用过去时，持续职责用现在时，具体已完成任务仍可用过去时。

英文描述优先用明确的动作和对象，减少逐字翻译。不要把“参与”扩大为 `Led`，或把团队结果写成本人的独立成果。每次更新任一版本后，同步检查另一版本的日期、成绩、贡献与论文状态。Word 和 LaTeX 正文分别维护，也需要手动同步。

## 排版与导出

- **页数按内容与要求决定。** 经历较少时一页通常足够，多项研究和成果可用两页或更多；模板示例的页数不是固定要求。完整学术 CV 与限定页数的申请简历要求可能不同，按申请方说明取舍。不要靠持续缩小字体和页边距压成一页。
- **保持清晰的阅读顺序。** 标题、日期和条目样式统一；避免栏目标题单独留在页末或一条经历被不合理地拆开。多页时可添加姓名和页码，便于辨识。
- **校徽和照片均按需使用。** 校徽选申请人就读或毕业院校的标识，不使用目标院校校徽暗示所属关系。照片是否提供遵循申请要求与当地惯例，模板预留位置不表示必须提供。使用时保持原始比例，不使用时处理掉占位框。
- **图标以辅助阅读为限。** 邮箱、电话和网址保留可读文字，避免仅用图标表达含义；无需额外堆放学校或软件标识。
- **检查最终提交文件。** 按要求提交文件格式；要求 PDF 时，导出后重新打开，检查字体、分页和链接，并确认正文能正常选中、复制。文件名可用 `Name_CV_EN.pdf` 或 `Name_CV_ZH.pdf`，将 `Name` 换成本人姓名，按需加日期或申请标识。

模板选择、编译、图片替换及样式设置见 [README](../README.md#快速开始)。本指南中的骨架是内容示意，不是可直接编译的 LaTeX 代码。

LaTeX 中文正文为 13 pt、行距为 17.8 pt，英文正文为 10.5 pt；章节之间和相邻教育、实习条目之间保留间隔。中英文字号按各自阅读效果设置，不必强行使用同一个数值。需要调整时统一修改样式文件，避免逐段缩放。

| LaTeX 命令 | 用途 |
| --- | --- |
| `\educationentry{学校及院系}{专业}{学位}{日期}` | 中文四列上下对齐，教育标题行整体加粗；英文分两行展示 |
| `\internshipentry{单位}{部门或岗位}{日期}` | 将实习标题信息放在同一行，较长名称可换行 |
| `\resumeentrysep` | 在相邻教育或实习条目之间增加适量间隔 |
| `\cvname{本人姓名}` | 论文署名加粗并加下划线 |
| `\resumeemailicon`、`\resumephoneicon`、`\resumelocationicon` | 邮箱、电话和所在地图标，旁边保留联系方式文字 |
| `\href{网址}{\resumegithubicon GitHub}` | GitHub 图标及文字链接 |
| `\href{网址}{\resumehomepageicon 个人主页}` | 个人主页图标及文字链接 |
| `\href{网址}{\resumewebicon 姓名}` | 网络图标和姓名共同作为链接 |
| `\href{网址}{\resumescholaricon Scholar}` | 学术主页图标及文字链接 |

编译时保留 `latex/assets/` 中的图标 PDF；它们是模板素材，不是编译生成的简历 PDF。完整列表与来源见 [图标说明](../latex/assets/README.md)。源码中已经注释的独立项目与自我评价模块可按需启用。

## 提交前检查

- [ ] 已阅读申请说明，满足格式、页数、语言、照片及必填信息要求。
- [ ] 姓名、邮箱和电话准确，相关主页与成果链接可以访问。
- [ ] 学位、就读时间、预计毕业时间及成绩与申请表、成绩单等材料一致。

- [ ] 论文作者顺序、年份和发表状态已更新；未录用的稿件没有被写成已录用成果。
- [ ] 中英文及本次使用的 Word、LaTeX 版本事实一致，已保存本次申请版本。
- [ ] 已删除不适用的栏目、所有填写提示、示例邮箱和未替换的图片占位框。
- [ ] 已逐项处理 Word 修订并删除批注，检查最终文件的分页、字体及文字显示。
